Other apps read and write Columbus through a small JSON API. Every response is JSON, and CORS is enabled, so browser apps on any origin can call it. This server's base address is {{ORIGIN}}.

Create a key on the Settings page, or call POST /api/sessions. Then send the key in a header with each request.

Authentication

Send your API key in the x-api-key header. Keep it secret: anyone with the key can read and write this session.

curl -H "x-api-key: YOUR_API_KEY" "{{ORIGIN}}/api/session/SESSION_ID"

A share link gives read-only access. Read endpoints accept share=TOKEN in the query string, in place of a key. Share tokens cannot save positions or manage keys. Browsers cannot send headers with EventSource, so the live viewer uses the share token.

POST/api/sessions

Creates a session with its own API key and share token. No key is needed. The key is returned only once, so save it.

curl -X POST "{{ORIGIN}}/api/sessions"

Response, 201 Created

{
  "session_id": "ses_4EduMzbopj_r",
  "api_key": "lt_4PR…",
  "share_token": "lts_1…",
  "created_at": "2026-11-06T13:38:42.534Z"
}

POST/api/location

Saves one position for the session that owns the key. The tracker sends one every 10 seconds. Needs an API key. A share token gets 403.

Body

latRequired. Latitude from -90 to 90.
lngRequired. Longitude from -180 to 180.
accuracyOptional. Accuracy radius in metres, zero or more.
speedOptional. Speed in metres per second, zero or more.
timestampOptional. ISO 8601 text or epoch milliseconds, for the time of the GPS fix. Defaults to the time the server received the request.
session_idOptional. If sent, it must match the key's session.
curl -X POST "{{ORIGIN}}/api/location" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"lat": 51.5007, "lng": -0.1246, "accuracy": 8, "speed": 3.2}'

Response, 201 Created

{
  "id": 42,
  "session_id": "ses_4EduMzbopj_r",
  "lat": 51.5007,
  "lng": -0.1246,
  "accuracy": 8,
  "speed": 3.2,
  "timestamp": "2026-11-06T13:40:02.118Z"
}

GET/api/location/latest

Returns the newest position for the session. Works with an API key or a share token. Returns 404 until the first position arrives.

session_idOptional with an API key, which already identifies the session. Required with a share token.
shareOptional. A share token, used instead of the key.
curl -H "x-api-key: YOUR_API_KEY" "{{ORIGIN}}/api/location/latest?session_id=SESSION_ID"

Response, 200 OK

{
  "id": 42,
  "session_id": "ses_4EduMzbopj_r",
  "lat": 51.5007,
  "lng": -0.1246,
  "accuracy": 8,
  "speed": 3.2,
  "timestamp": "2026-11-06T13:40:02.118Z"
}

GET/api/location/history

Returns the most recent positions, oldest first, so the array reads as a trail. Works with an API key or a share token.

session_idOptional with an API key. Required with a share token.
limitOptional. A whole number from 1 to 1000. Defaults to 100.
shareOptional. A share token, used instead of the key.
curl -H "x-api-key: YOUR_API_KEY" "{{ORIGIN}}/api/location/history?limit=30"

Response, 200 OK

{
  "session_id": "ses_4EduMzbopj_r",
  "count": 2,
  "points": [
    { "id": 41, "session_id": "ses_4EduMzbopj_r", "lat": 51.5006, "lng": -0.1248, "accuracy": 9, "speed": 3.0, "timestamp": "2026-11-06T13:39:52.094Z" },
    { "id": 42, "session_id": "ses_4EduMzbopj_r", "lat": 51.5007, "lng": -0.1246, "accuracy": 8, "speed": 3.2, "timestamp": "2026-11-06T13:40:02.118Z" }
  ]
}

GET/api/session/:id/stream

Live updates as Server-Sent Events. The first event is ready, which carries the latest position or null. Each new position then arrives as a location event. If the key is replaced or revoked, or the share link is reset, a revoked event arrives and the stream ends.

x-api-keyHeader. Use it from servers and apps.
shareQuery string. Use it for browser viewers, because EventSource cannot send headers.
curl -N -H "x-api-key: YOUR_API_KEY" "{{ORIGIN}}/api/session/SESSION_ID/stream"

Browser viewer

const stream = new EventSource("{{ORIGIN}}/api/session/SESSION_ID/stream?share=SHARE_TOKEN");
stream.addEventListener("location", (event) => {
  const point = JSON.parse(event.data); // { id, lat, lng, accuracy, speed, timestamp }
  console.log(point.lat, point.lng);
});

Events

ready{ "session_id", "latest" }. Sent once, when the stream opens.
locationOne position, in the same shape as the save response.
revoked{ "session_id", "reason" }. The stream ends after this event.

GET/api/session/:id

Session details for the key's own session. The key itself is never returned, only its last four characters.

{ "session_id": "ses_4EduMzbopj_r", "active": true, "created_at": "2026-11-06T13:38:42.534Z", "api_key_hint": "HhZo" }

POST/api/session/:id/key

Replaces the API key. The old key stops working straight away, and streams opened with it are closed. The history stays. Returns the new key once.

{ "session_id": "ses_4EduMzbopj_r", "api_key": "lt_…" }

DELETE/api/session/:id/key

Revokes the key. The key and the share link stop working, every open stream ends, and the tracker stops. Positions already stored are kept.

{ "session_id": "ses_4EduMzbopj_r", "revoked_at": "2026-11-06T14:02:10.441Z" }

POST/api/session/:id/share-link

Replaces the share token. The old link stops working, and anyone viewing with it is disconnected.

{ "session_id": "ses_4EduMzbopj_r", "share_token": "lts_…" }

GET/api/health

Checks that the server is running. Needs no key.

{ "ok": true, "time": "2026-11-06T13:38:42.534Z" }

Data format

idInteger. Increases with every saved position.
session_idText. The session the position belongs to.
lat, lngDecimal degrees, WGS 84.
accuracyMetres, or null if the device did not report it.
speedMetres per second, or null if the device did not report it.
timestampISO 8601 in UTC, for the time of the GPS fix.

Errors

Errors are JSON, in the form { "error": "message" }.

400Invalid input, such as a latitude out of range or a limit that is not a whole number from 1 to 1000.
401Missing, invalid or revoked credentials.
403Credentials that belong to another session, or a share token used to write.
404Nothing recorded yet, or an unknown endpoint.
405The method is not allowed on this endpoint.
413The request body is larger than 16 KB.

Notes

Only SHA-256 hashes of keys and share tokens are stored. Positions are stored until the database file is deleted. Requests are not rate limited in this version, so put the server behind HTTPS and a proxy if it is exposed to the internet.
